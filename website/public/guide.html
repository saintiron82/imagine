1. Installation

Windows

  1. Download the Windows (.zip) package from the Download page.
  2. Extract the zip file to any folder (e.g., C:\Imagine).
  3. Double-click Imagine.exe to launch the app.
  4. On first launch, the setup wizard will guide you through model installation.

macOS

  1. Download the macOS (.dmg) package from the Download page.
  2. Open the .dmg and drag Imagine to your Applications folder.
  3. Launch Imagine from Applications. If prompted about unverified developer, go to System Settings > Privacy & Security and click "Open Anyway".
  4. The setup wizard will handle AI model downloads automatically.
Tip

A GPU with 6GB+ VRAM is recommended for optimal performance. The app works on CPU but processing will be significantly slower.

2. Getting Started

  1. On first launch, select your domain preset (Game Asset, Illustration, Stock Photo, or General). This determines how the AI categorizes and tags your images.
  2. Choose your AI tier based on your hardware: Standard (6GB VRAM), Pro (8-16GB), or Ultra (20GB+).
  3. Add folders containing your image assets (PSD, PNG, JPG) using the Discover button. The app will recursively scan and process all supported files.
  4. Wait for the pipeline to complete. You can monitor progress in the status bar showing the current phase (Parse > Vision > Embed).
  5. Once processing is done, use the Search tab to find images by text description, visual similarity, or keywords.

3. Server Mode

Server mode lets your team search and manage assets together. One person runs the server, and others connect via web browser.

  1. Click the [Server] toggle button in the top-right corner of the app.
  2. Set a port number and create a Group Name. The group name helps team members find your server on the Servers page.
  3. The server starts automatically. Your server address and group info will be registered to the public server directory.
  4. Share the server address or group name with your team. They can access it by visiting http://your-ip:port in their browser, or by finding your group on the Servers page.
Tip

In server mode, the first user account becomes the admin. Use the Admin panel to manage users and invite codes.

4. Connecting Workers

Workers are separate machines that process images for the server. This allows you to distribute heavy AI processing across multiple GPUs.

  1. In the Admin panel, go to Worker Tokens and create a new token.
  2. Copy the generated setup command or download the setup script.
  3. Run the setup script on the worker machine. It will automatically install dependencies and connect to the server.
  4. The worker will start claiming and processing jobs from the server queue automatically.
Note

Each worker should run on a separate GPU machine. Running multiple workers on the same GPU does not improve throughput due to GPU time-sharing contention.

5. Group Search

The Servers page shows all registered Imagine servers. You can find your team's server by group name.

  1. Visit the Servers page on this website.
  2. Browse the server list or search by group name.
  3. Find your team's server and note the connection address.
  4. Enter the server address in your browser to access the shared Imagine workspace.

6. Triaxis Search

Imagine uses a three-axis search system called Triaxis to find images with maximum accuracy. When you type a search query, all three axes work together to find the best results.

👁

VV (Visual Vector)

Finds images that look visually similar. Powered by SigLIP2 AI vision model.

💡

MV (Meaning Vector)

Understands the meaning of your text query and matches it against AI-generated image descriptions.

🔎

FTS (Full-Text Search)

Searches file names, layer names, and tags by exact keyword matching.

Results from all three axes are combined using RRF (Reciprocal Rank Fusion) to give you the most relevant results. You can also use the search mode dropdown to prioritize specific axes for different use cases.

Tip

For best results, try natural language queries like "fantasy knight holding a sword" rather than short keywords. The MV axis excels at understanding descriptive queries.
